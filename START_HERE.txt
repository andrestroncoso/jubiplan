PROBLEMAS COMUNES Y SOLUCIONES
───────────────────────────────

"Error: npm no encontrado"
→ Necesitas instalar Node.js
→ Descargalo de https://nodejs.org/

"Puerto 3000 ya está en uso"
→ Otro programa usa ese puerto
→ Cambia en .env: PORT=3001
→ O cierra la otra aplicación

"Página en blanco"
→ Espera a que cargue (3-5 segundos)
→ Abre consola (F12) para ver errores
→ Recarga (Ctrl+R)

"API no responde"
→ Verifica terminal: dice "Servidor ejecutándose"?
→ Si no, ejecuta: npm run dev
→ Si sí, recarga la página
