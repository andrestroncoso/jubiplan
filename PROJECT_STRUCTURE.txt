┌─────────────────────────────────────────────────────────────────┐
│                      FLUJO 1: CÁLCULO                          │
├─────────────────────────────────────────────────────────────────┤

│   ↓                                                             │
│ Frontend (app.js) → Valida básicamente                         │
│   ↓                                                             │

│   ↓                                                             │
│ Backend (server.js) → Valida parámetros                        │
│   ↓                                                             │
│ PensionCalculator → Cálculo actuarial                          │
│   ↓                                                             │
│ Respuesta JSON → Retorna resultado                             │
│   ↓                                                             │
│ Frontend → Renderiza gráfico                                   │
│   ↓                                                             │
│ Usuario → Ve resultados y gráfico                              │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                 FLUJO 2: CARGAR AFPs E ISAPRES                 │
├─────────────────────────────────────────────────────────────────┤
│ Usuario → Hace clic en tab "AFP e Isapres"                     │
│   ↓                                                             │
│ Frontend → GET /api/afps                                       │
│ Frontend → GET /api/isapres (paralelo)                         │
│   ↓                                                             │
│ Backend → Lee afps.json e isapres.json                         │
│   ↓                                                             │
│ Retorna datos como JSON                                        │
│   ↓                                                             │
│ Frontend → Renderiza tarjetas                                  │
│   ↓                                                             │
│ Usuario → Explora instituciones y planes                       │

ENDPOINTS API:

GET /api/afps
├── Retorna: { afps: [...] }
└── Uso: Llenar tab "AFP e Isapres"

GET /api/isapres
├── Retorna: { isapres: [...] }
└── Uso: Llenar tab "AFP e Isapres"

POST /api/calcular-pension
├── Body: { salarioMensual, edadActual, edadJubilacion, ... }
├── Retorna: { saldoFinal, pensionMensual, aportesRegimen, ... }
└── Uso: Calcular pensión simulada

POST /api/comparar-afps
├── Body: { saldoFinal }
├── Retorna: { afps: [...con comparativa...] }
└── Uso: Comparar rendimiento entre AFPs

GET /api/health
├── Retorna: { status: "OK" }
└── Uso: Verificar que servidor está activo

   - Considera aporte obligatorio (10%)

   - Texto grande (16px base, escalable)
   - Colores de alto contraste
   - Sin animaciones molestas

✅ Comparador de Instituciones
   - 4 AFPs con detalles completos
